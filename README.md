# STM32MP157 — a Buildroot system, built from scratch

A complete embedded Linux system for the **STM32MP157A Discovery Kit 1**, generated by
[Buildroot](https://buildroot.org/) **2025.02.6** from a 40-line defconfig: bootloader, kernel,
an out-of-tree I²C driver, four custom packages and a flashable SD card image.

Done as the practical labs of Bootlin's [Buildroot system development](https://bootlin.com/training/buildroot)
course. **This repository contains only my own work** — the configuration, the packaging and the
board files. Bootlin's lab data (the base kernel config, the Nunchuk kernel patches, the upstream
sources of the demo applications) is not reproduced here.

```
                    STM32MP157A-DK1  (dual Cortex-A7)
                                 │
   U-Boot SPL ──> U-Boot ──> extlinux ──> Linux 6.12.47 ──> BusyBox init
   (fsbl1/fsbl2)   (ssbl)    (in rootfs)        │
                                               ├─ wiichuck ──I²C @0x52──> Wii Nunchuk
                                               │      └─ /dev/input/event0 ─> evtest
                                               ├─ nInvaders (ncurses)
                                               ├─ myapp (libconfig)
                                               ├─ bar / libfoo
                                               └─ Dropbear ── ssh 192.168.1.100
                                 │
                    one sdcard.img, built by genimage
```

## What is in here

| Directory | What it is |
|---|---|
| [`br2-external/`](br2-external/) | The **BR2_EXTERNAL tree**: defconfig, board files, rootfs overlay, and the `bar` / `libfoo` / `myapp` packages |
| [`package/ninvaders/`](package/ninvaders/) | An **in-tree Buildroot package** for nInvaders — public open source, so it belongs in Buildroot itself |

Two locations, one deliberate distinction: project-specific things stay out of the Buildroot
tree, publicly reusable packages go in it.

## The labs, and what each one produced

| Lab | Subject | My output |
|---|---|---|
| 1 | **Basic usage** | Configured a minimal bootable system from scratch rather than reusing `stm32mp157a_dk1_defconfig`: ARM Cortex-A7 EABIhf, external Bootlin toolchain, Linux 6.12.47 with a custom config, U-Boot 2025.07 with SPL, GPT-partitioned SD card |
| 2 | **Root filesystem** | Rootfs overlay for the network configuration, a **post-build script** stamping `/etc/build-id`, kernel patched via `BR2_GLOBAL_PATCH_DIR` for the Wii Nunchuk, kernel config updated with `linux-update-defconfig`, kernel + DTB + `extlinux.conf` moved into the root partition, defconfig saved with `savedefconfig`, full rebuild verified **out of tree** |
| 3 | **New packages** | [`package/ninvaders/`](package/ninvaders/) — `generic-package` with an ncurses dependency, a `-fcommon` workaround for a pre-gcc-10 codebase, hand-written install commands and a hash file |
| 4 | **Advanced packaging** | [`libfoo`](br2-external/package/libfoo/) (GitHub + autoreconf + staging + post-install hook + Kconfig sub-option) and [`bar`](br2-external/package/bar/) (mandatory *and* optional dependency, hashes, upstream bug fixed by a `git format-patch` patch) |
| 5 | **Advanced aspects** | Build-time / dependency / size graphing, licensing report, and the migration of everything project-specific into a **BR2_EXTERNAL** tree — plus `genimage` to produce a single flashable `sdcard.img` |
| 6 | **Application development** | [`myapp`](br2-external/package/myapp/) — my own libconfig application, cross-compiled with `pkg-config`, remote-debugged with `gdbserver` + cross gdb, then packaged with the `local` site method |

## Highlights

**Wrote four Buildroot packages, one per infrastructure and dependency pattern.**
`generic-package` for a Makefile-only game, `autotools-package` twice — once for a GitHub library
needing `AUTORECONF` and a staging install, once for an application with both a mandatory and an
*optional* dependency — and the `local` site method for code under active development.

**Fixed an upstream bug the way it should be fixed.** Enabling `libconfig` broke `bar` with
`error: unknown type name 'config_t'`: upstream uses the library without including its header.
Editing `output/build/` makes the error go away until the next `make clean`, so the fix is carried
as a [real patch](br2-external/package/bar/0001-Fix-missing-libconfig.h-include.patch) generated
with `git format-patch`, applied by Buildroot at the *Patching* step.

**Made a 2003 codebase cross-compile.** nInvaders fails on modern toolchains because gcc 10
defaults to `-fno-common` and its Makefile has no `install:` rule. Both are solved in the package
rather than by forking the source — see [`ninvaders.mk`](package/ninvaders/ninvaders.mk).

**Moved the project out of the Buildroot tree.** The pre-BR2_EXTERNAL defconfig had an absolute
path from my machine baked into `BR2_LINUX_KERNEL_CUSTOM_CONFIG_FILE`. Reworking everything
against `$(BR2_EXTERNAL_FOOBAR_PATH)` made the configuration portable and left Buildroot a
pristine checkout that updates with a `git pull`.

**Replaced the manual flashing ritual with one image.** The labs partition the SD card by hand
with `parted`, `mkfs` and four `dd` commands. A [`genimage.cfg`](br2-external/board/bootlin/stm32mp1/genimage.cfg)
plus a post-image script produce a single `sdcard.img` — GPT, both SPL copies, U-Boot and a
bootable ext4 rootfs — that goes onto the card in one `dd`.

**Added a driver to the kernel through Buildroot, not by hand.** `BR2_GLOBAL_PATCH_DIR` applies
the Nunchuk driver and Device Tree patches to Linux 6.12.47 before it is built, and the kernel
config change enabling `CONFIG_JOYSTICK_WIICHUCK` is versioned as a
[delta](br2-external/board/bootlin/stm32mp1/linux-stm32mp1.config.delta.diff) saved with
`make linux-update-defconfig`. No manual `insmod`, no config drift.

## Building

```sh
git clone https://gitlab.com/buildroot.org/buildroot.git
cd buildroot && git checkout -b bootlin 2025.02.6
cp -r /path/to/package/ninvaders package/
echo 'source "package/ninvaders/Config.in"' >> package/Config.in   # inside the Games menu

mkdir ~/buildroot-build && cd ~/buildroot-build
make -C /path/to/buildroot O=$(pwd) BR2_EXTERNAL=/path/to/br2-external bootlin_defconfig
make 2>&1 | tee build.log
```

Three Bootlin-provided files must be dropped into the tree first — see
[`br2-external/README.md`](br2-external/README.md#assembling-a-working-tree).

Flash and boot:

```sh
sudo dd if=images/sdcard.img of=/dev/mmcblk0 bs=1M conv=fdatasync
picocom -b 115200 /dev/ttyACM0
```
